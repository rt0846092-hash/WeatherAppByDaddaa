# WeatherAppByDaddaa
A modern React weather app that shows real-time weather, city-based local time, and 5-day forecasts using the OpenWeather API.

# 🌦️ Weather App

A responsive weather application built using React that provides real-time weather updates for any city.

---

## 🚀 Features

* 🌍 Search weather by city name
* 🌡️ Real-time temperature updates
* ☁️ Weather conditions (Cloudy, Rainy, Sunny, etc.)
* 💨 Wind speed and humidity details
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* ⚛️ Frontend: React.js
* 🎨 Styling: CSS
* 🌐 API: OpenWeatherMap API

## ⚙️ Installation

1. Clone the repository:

```bash
git clone https://github.com/rt0846092-hash/weather-app.git

```

2. Navigate to the project folder:

```bash
cd my-weather-app
```

3. Install dependencies:

```bash
npm install
```

4. Start the app:

```bash
npm start
```

---

## 🔑 API Setup

1. Get your API key from https://openweathermap.org/api
2. Create a `.env` file in the root folder
3. Add your API key like this:

```env
REACT_APP_API_KEY=your_api_key_here
```

➡️ Important:

* Never upload `.env` file to GitHub
* Add `.env` to `.gitignore`
